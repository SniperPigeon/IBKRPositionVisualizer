# IBKR 交易回看

把 IBKR 活动账单（Activity Statement CSV）里的成交画到 K 线上，风格参考富途：B/S 标记、MA5/10/20/30、成交量、MACD、持仓曲线、成本线。

## 运行

```bash
python3 server.py ~/Downloads/U1234567_20260101_20261118.csv
```

会自动打开 http://127.0.0.1:8765 。不带参数启动的话，可以直接把 CSV 拖进页面；多份账单可以一起拖入，会自动去重。

- 只依赖 Python 标准库（3.9+），不需要 pip install
- 账单只在浏览器里解析，不会上传；发往 Yahoo 的只有股票代码和时间范围
- 图表库 lightweight-charts 5.0.8 从 unpkg 加载

## 功能

- 日K / 周K / 月K / 60分 / 15分 / 5分；周K和月K由日K在本地聚合
- 买点 B 在 K 线下方，卖点 S 在上方，虚线连到实际成交价；同一根 K 线有多笔成交时显示数量角标
- 鼠标悬停看明细（时间、数量、价格、已实现盈亏），点标记会高亮表格里对应的行；点表格行会把图表定位到那天
- 期权成交（C/P，紫色）和持仓转入（“转”，蓝色）显示在正股图上，可以单独开关
- 拆股自动复权：用 Yahoo 的拆股事件，把拆股前的成交价和数量换算成复权口径（比如 SOXX 在 2026-11-05 的 3:1 拆股）
- 美股 20:00 ET 之后的隔夜盘成交算到下一个交易日的 K 线
- 支持深色/浅色主题，以及红涨绿跌/绿涨红跌切换

## 行情缓存

`cache/<代码>_<周期>.json`：

- 日线 30 分钟、分钟线 2 分钟内直接读本地缓存，不联网
- 过期后只增量拉取最近几天的数据，与本地合并
- 发现新的拆股时，按比例把本地旧数据复权
- Yahoo 只提供最近 60 天的 5/15 分钟线，但本地缓存会一直保留，所以分钟线历史会越攒越长
- 断网时退回本地缓存（页面会提示）
- 「↻ 刷新行情」会跳过缓存；删掉 `cache/` 目录就是完全重来

## 已知限制

- 账单时间按美东时间解析（IBKR 活动账单的默认设置）
- 非美股的 Yahoo 代码是按币种猜的（SGD → .SI，HKD → .HK 等）。如果对不上，可以在标题旁的 Yahoo 输入框里手动改，改动会记在浏览器里
- 期权只标在正股图上，不画期权自己的价格
